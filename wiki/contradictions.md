# Contradictions

> LLM이 새 source를 wiki에 통합할 때, 기존 fact와 모순되는 새 fact 발견 시 여기 기록.
> **사람이 정기적으로 review해서 해소** — 갱신인지 / 둘 다 사실인지 / 한 쪽이 틀린 정보인지 판단.

## 형식

```
## YYYY-MM-DD — wiki/<page>.md

- 기존: "<fact>" (raw/<source1>)
- 새: "<fact>" (raw/<source2>)
- 검토 필요: <어떤 판단이 필요한지 한 줄>
- (해소되면 아래 추가)
- 결정: <갱신 / 둘 다 사실 / 기존 폐기 등>
- 결정자: <user>
- 결정일: YYYY-MM-DD
```
